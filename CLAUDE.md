# Claude Code Instructions

Read and follow `AGENTS.md` before changing this repository. Exit gates through Phase 5 are in
`docs/DEVELOPMENT_PLAN.md`; Phases 6-9 are in `docs/PHARMACY_OS_COMPLETION_ROADMAP.md`.

Before completing a task:

1. Preserve the exact-money, tenancy, append-only-ledger, idempotency, and lock-ordering invariants in `AGENTS.md`.
2. Run `npm run verify`.
3. Document the commands, exit codes, and any unverified operational assumptions.
4. Do not claim a phase or gate is complete merely because code or configuration exists.
